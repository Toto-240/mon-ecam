MON ECAM - version hébergée sur GitHub (gratuite, toujours en ligne)

Comment ça marche
  Toutes les 2 heures, GitHub lance ecam_scraper.py sur ses machines,
  chiffre les données avec ton mot de passe d'appli, puis publie l'appli
  sur GitHub Pages. Ton PC n'a pas besoin d'être allumé.

Les 3 secrets à créer (Settings > Secrets and variables > Actions)
  ECAM_USER       ton identifiant ECAM
  ECAM_PASSWORD   ton mot de passe ECAM
  APP_PASSWORD    un mot de passe NOUVEAU, inventé pour l'appli
                  (c'est lui que tu taperas sur ton téléphone)

Activer la publication
  Settings > Pages > Source : "GitHub Actions"

Forcer une synchro
  Onglet Actions > Synchro ECAM > Run workflow
  (ou le lien "Forcer une synchro" en haut de l'appli)

Tester en local (facultatif)
  pip install -r requirements.txt
  python ecam_scraper.py            (avec un fichier .env, voir .env.example)

APPLI IPHONE (.ipa)
  GitHub la fabrique tout seul (onglet Actions > "Appli iPhone (IPA)").
  Le fichier MonECAM.ipa apparaît dans la section "Releases" du dépôt.

  Installation depuis le PC Windows :
  1. Installe iTunes et iCloud (versions du site d'Apple, pas du Microsoft Store)
  2. Installe Sideloadly (sideloadly.io)
  3. Branche l'iPhone en USB, glisse MonECAM.ipa dans Sideloadly,
     entre ton identifiant Apple, clique Start
  4. Sur l'iPhone : Réglages > Général > VPN et gestion de l'appareil > Faire confiance
     (et si demandé : Réglages > Confidentialité et sécurité > Mode développeur)

  Avec un compte Apple gratuit, l'appli expire au bout de 7 jours :
  relance simplement Sideloadly. L'appli affiche toujours la dernière
  version du site, donc pas besoin de la réinstaller quand on la modifie.
